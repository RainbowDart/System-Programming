# Решения — занятие 05

- Валидация: `string.IsNullOrWhiteSpace(name)` и `delay < TimeSpan.Zero`.
- `await Task.Delay(delay, cancellationToken)` освобождает поток на время ожидания; `Thread.Sleep` блокирует поток.
- Последовательный вариант: `await` внутри цикла.
- Параллельный вариант: сначала `Select`/`ToArray` для создания всех задач, затем `await Task.WhenAll(tasks)`.
- `async` сам по себе не создаёт поток. `Task` представляет операцию; `await` асинхронно ожидает её завершения.
- Для меню: не использовать `.Wait()`/`.Result`; для настоящего управления во время длительной операции запустить её отдельной задачей, читать команды управления и поддержать `CancellationTokenSource`.
- Исключения перехватывать адресно: `OperationCanceledException` отдельно, остальные — с выводом типа и сообщения.
